## Context

§2 *Betting rules*: "The rider on the button acts first in every betting round. The button passes
each hand." Passing the button assumes a previous hand against the same opponent, as in a rematch.
A match is one hand (0005), and the yard pairs riders who kept their hands (0006), so two strangers
meeting for the first time have no previous hand to pass it from. §2 was silent on who gets it.

The options put to Trey, in the prefold cost session:

- **Random:** "A coin flip at the match, shown on the joust banner. Neutral. In a rematch the button
  then passes each hand, as §2 says. Acting first is usually the weaker seat in betting, so tying
  the button to anything a rider did would turn it into a reward or a penalty."
- **Waited longer:** the rider who has been in the yard longer gets the button. That rewards or
  punishes waiting, depending on whether the button helps.
- **Leave open** for the queue design.

## Decision

Trey chose **Random**.

- In a first match the button is decided by a coin flip at the match, shown to both riders. In a
  rematch it passes each hand, as before.

## Consequences

- §2 *Betting rules* says so.
- Nothing in the sim changes. Its runner already alternates the button hand by hand, which over many
  hands gives each seat the button half the time, the same as a coin flip.
