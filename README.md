# Poker Jousting

A Roblox 1v1 game where a Texas hold'em hand is played as four jousting passes. Cards buff
the riders; a radial aim dial decides who lands the hit. Every bet is a commitment to ride
into the next card.

## Status

Pre-production. The repo holds the design only; no game code yet. Repo working rules and
workflow come next, before any implementation.
